About Us

GameVault is a simple game collection project created to demonstrate a local Git workflow, feature branches, merging, ignore rules, and reverting commits.

Project features

  • A simple home page and about page.
  • Separate feature branch for the project description.
  • Git ignore rules for log files and temporary folders.
